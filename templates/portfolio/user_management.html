Uso recomendado

Como mantener el acceso seguro

Administrador principal

Mantén al menos un usuario administrador activo para no depender del modo recuperacion.

Usuarios normales

Para consulta diaria o carga de datos, crea usuarios normales. Solo los administradores podran gestionar mas accesos.

Emergencia en servidor

Si alguna vez nadie puede iniciar sesion, sigue existiendo el comando `ensure_household_user --staff --superuser` como via de rescate desde consola.
